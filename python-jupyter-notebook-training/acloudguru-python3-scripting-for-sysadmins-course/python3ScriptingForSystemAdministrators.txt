5.5 Lists

    Sequence Types - list, tuple, range
      https://docs.python.org/3/library/stdtypes.html#sequence-types-list-tuple-range

     List:
       https://docs.python.org/3/library/stdtypes.html#list


   Lists are mutable data types
     - data/items in a list can be changed


   Create a simple list (notation: inside square brackets and each item separated by a comma):
   my_list = [1, 2, 3, 4, 5]
   -> lists can contains items of different types (heterogenous)
   my_list1 = [1, 'a', True]

   subscript operation or indexing into a list; syntax: <listName>[<index>]
      my_list[0]  -> returns: 1

    if <index> exceeds elements in list, then:
      my_list[5] -> returns: IndexError: list index out of range

    list length: len(<listName>)
     len(my_list) -> returns: 5
     negative indexing (index from last item in list):
      my_list[-1] -> returns 5

   list slice or subsection: syntax <listName>[<startingIndex>:<endingIndex>:<stepValue>]
        notes: 1. does not include endingIndex item; <stepValue> defaults to 1
      my_list[0:3] -> returns  [1, 2, 3]

      slice starting with <startingIndex> : syntax <listName>[<startingIndex>:]
      my_list[3:] -> returns  [4, 5]

      slice up to <endingIndex> : syntax <listName>[:<endingIndex>]
      my_list[:3] -> returns  [1, 2, 3]

      step through a list with non-one step:
       my_list[0::2]  -> returns [1, 3, 5]

      Change item(s) in list with subscript operation: syntax <listName>[<index>] = <newItmem>
        my_list[0] = "a"
        my_list  -> returns:  ['a', 2, 3, 4, 5]

      Append to end of list using "append()" operator <listName>.append(<appendItems>)
        my_list.append(6)
        my_list.append(7)
        my_list -> returns: ['a', 2, 3, 4, 5, 6, 7]

      Append to end of list using "+=" operator <listName> += [<appendItems>]
        my_list += [8, 9, 10]
        my_list -> returns: ['a', 2, 3, 4, 5, 6, 7, 8, 9, 10]

      Change a slice of the list <listName>[<startingIndex>:<endingIndex>] += [<appendItems>]
          my_list[1:3] = ['b', 'c']
          my_list -> returns: ['a', 'b', 'c', 4, 5, 6, 7, 8, 9, 10]

      Change a slice of the list: <listName>[<startingIndex>:<endingIndex>] += [<appendItems>]
         where <appendItems> has more items than being replaced -> this will expand list
          my_list[3:5] = ['e', 'e', 'f']
          my_list -> returns: ['a', 'b', 'c', 'e', 'e', 'f', 6, 7, 8, 9, 10]


      Remove a slice from the list: <listName>[<startingIndex>:<endingIndex>] = []
        my_list = ['a', 'b', 'c', 'e', 'e', 'f', 5, 6, 7]
        my_list[4:] = []
        my_list -> returns: ['a', 'b', 'c', 'e']

      remove() method: removes item matching <listName>.remove(<removeItem>)
         my_list.remove('b')
         my_list -> returns: ['a', 'c', 'e']

      remove() an item that is not in list:
           my_list.remove('x') -> returns: ValueError: list.remove(x): x not in list

        pop() item off list  -> also returns item popped off of list: syntax <listName>.pop(<index>)
          where <index> default is last item in list
         my_list.pop() -> returns: 'e'
         my_list        -> returns: ['a', 'c']
         my_list.pop(0) -> returns: 'a'
         my_list        -> returns: ['c']

         pop() item at index greater than items in list
         my_list.pop(1) -> returns: IndexError: pop index out of range

         pop from an empty list:
         [].pop()  -> returns: IndexError: pop from empty list

5.6 Tuples

  Sequence Types - list, tuple, range
    https://docs.python.org/3/library/stdtypes.html#sequence-types-list-tuple-range

      - There are three basic sequence types: lists, tuples, and range objects.
      - Additional sequence types tailored for processing of binary data and text strings are described in dedicated sections.

      Common Sequence Operations

        - The operations in the following table are supported by most sequence types, both mutable and immutable.
        - The collections.abc.Sequence ABC is provided to make it easier to correctly implement these operations on
          custom sequence types.

        - This table lists the sequence operations sorted in ascending priority.
        - In the table, s and t are sequences of the same type, n, i, j and k are integers and x is an arbitrary
          object that meets any type and value restrictions imposed by s.

        - The 'in' and 'not in' operations have the same priorities as the comparison operations.
        - The + (concatenation) and * (repetition) operations have the same priority as the corresponding numeric operations.

        Operation       Result
        ----------      -----------------------------------------------
	x in s          True if an item of s is equal to x, else False

	x not in s      False if an item of s is equal to x, else True

	s + t            the concatenation of s and t

	s * n or n * s   equivalent to adding s to itself n times

	s[i]             ith item of s, origin 0

	s[i:j]           slice of s from i to j

	s[i:j:k]         slice of s from i to j with step k

	len(s)           length of s

	min(s)           smallest item of s

	max(s)           largest item of s

	s.index(x[, i[, j]])     index of the first occurrence of x in s (at or after index i and before index j)

	s.count(x)        total number of occurrences of x in s`

  Tuples:
     https://docs.python.org/3/library/stdtypes.html#tuple


  Tuples
    - immutable sequences, typically used to store collections of heterogeneous data
    - no methods to modify/change (no remove() or pop() methods) a tuple because they are immutable
    - can concatenate because it returns a new tuple

   Tuples may be constructed in a number of ways:
     - Using a pair of parentheses to denote the empty tuple: ()
     - Using a trailing comma for a singleton tuple: a, or (a,)
     - Separating items with commas: a, b, c or (a, b, c)
     - Using the tuple() built-in: tuple() or tuple(iterable)


   Specify a tuple example:
     point = (2.0, 3.0)
     point -> returns: (2.0, 3.0)

   Concatentate (creates a new tuple)
     Note: need a trailing comma to denote a single item tuple
       point_3d = point + (4.0,)
       point_3d  -> returns: (2.0, 3.0, 4.0)

   Unpack a tuple to multipe variables
       x, y, z = point_3d
       x  -> returns: 2.0
       y  -> returns: 3.0
       z  -> returns: 4.0

   Pass values to print() using a tuple  (needed if more than one item and using Python 2 compatible print() syntax)
     print("My name is: %s %s" % ("Pat", "Hall"))

5.7 Dictionaries (dicts)

   Mapping Types - dict
     https://docs.python.org/3/library/stdtypes.html#mapping-types-dict

   Mapping Types - dict:
     - A mapping object maps hashable values to arbitrary objects.
     - Mappings are mutable objects.
     - There is currently only one standard mapping type, the dictionary

    Dictionaries can be created by several means:
      - Use a comma-separated list of key: value pairs within braces: {'jack': 4098, 'sjoerd': 4127} or
        {4098: 'jack', 4127: 'sjoerd'}
      - syntax: <dictName> = {<key1>:<value1>, ..., <keyN>:<valueN>}
      - Use a dict comprehension: {}, {x: x ** 2 for x in range(10)}
          dict comprehension general syntax:
            #Basic syntax
               {key: value for item in iterable}

            #With condition
               {key: value for item in iterable if condition}
          examples:
            squared = {x: x ** 2 for x in range(10)}
            squared -> returns: {0: 0, 1: 1, 2: 4, 3: 9, 4: 16, 5: 25, 6: 36, 7: 49, 8: 64, 9: 81}

            names = ['Alice', 'Bob', 'Charlie', 'David']
            name_lengths = {name: len(name) for name in names if len(name) > 4}
            print(name_lengths)
            # output: {'Alice': 5, 'Charlie': 7, 'David': 5}

      - Use the type constructor: dict(), dict([('foo', 100), ('bar', 200)]), dict(foo=100, bar=200)
         examples:
           empty_dict = dict()
           empty_dict -> returns: {}

           foo_bar = dict([('foo', 100), ('bar', 200)])
           foo_bar  -> returns: {'foo': 100, 'bar': 200}

           my_dict = dict(one=1, two=2, three=3)
           print(my_dict)  # Output: {'one': 1, 'two': 2, 'three': 3}

     Returning list of keys or values from a dict
        Using keys() method to return a list of keys: syntax: <dictName>.keys()
            ages.keys()  -> returns:  dict_keys(['kevin', 'bob'])
            # to return just the list of keys:
            list(ages.keys())  -> returns:  ['kevin', 'bob']

        Using values() method to return a list of values: syntax: <dictName>.values()
            ages.values()  -> returns:  dict_values([59, 40])
            # to return just the list of values:
            list(ages.values())  -> returns:  [59, 40]

     Alternative ways to create a dict
       Using dict() function  - named parameter version of the dict function:
           syntax:  <dictName> = dict (<key1>=<value1>, <key2>=<value2>, ..., <keyN>=<valueN>)
         weights = dict (kevin=160, bob=240, kayla=135)
          weights  -> returns:  {'kevin': 160, 'bob': 240, 'kayla': 135}

       Using dict() function  - list of tuples version of the dict function:
           syntax:  <dictName> = dict ([(<key1>,<value1>), (<key2>,<value2>), ..., (<keyN>,<valueN>)])
           colors = dict ([('kevin', 'blue'), ('bob', 'green'), ('kayla', 'red')])
           colors  -> returns:  {'kevin': 'blue', 'bob': 'green', 'kayla': 'red'}

6.1 Conditional and Comparisons

  Comparisons:
     https://docs.python.org/3/library/stdtypes.html#comparisons

    if/elif/else
      https://docs.python.org/3/tutorial/controlflow.html#if-statements

  Comparison operators:
      - There are eight comparison operations in Python.
      - They all have the same priority (which is higher than that of the Boolean operations).
      - Comparisons can be chained arbitrarily; for example, x < y <= z is equivalent to x < y and y <= z,
        except that y is evaluated only once (but in both cases z is not evaluated at all when x < y is found to be false).
      - MUST compare items of the similar types (note: can compare a float and int)
         - equal '==' and '!=' supported for dissimilar types

  Comparison operations:
        Operation  Meaning
        ---------  ---------------------------
          <        strictly less than
          <=       less than or equal
          >        strictly greater than
          >=        greater than or equal
          ==        equal
          !=        not equal
          is        object identity
          is not    not negated object identity


  Comparisons return True or False
     1 < 2  -> returns:  True
     0 > 2  -> returns:  False
     2 != 1 -> returns:  True

  Comparison of dissimilar types are not supported (e.g. float and str)
     3.1 <= "this"  -> returns:  TypeError: '<=' not supported between instances of 'float' and 'str'
  Comparison of similar types are supported (e.g. int and float)
     3 <= 3.1  -> returns:  True
  Equal '==' and not equal '!=' comparisons are supported for dissimilar types
      1.1 == "1.1"          -> returns:  False
    Plus Casting string to float type:
      1.1 == float("1.1")   -> returns:  True

  Char comparison
    - chars and strings can be compared using comparison operators such as >, <, >=, <=, ==, and !=.
    - The comparison is performed lexicographically, which means strings are compared character by character based on
      their Unicode code points
    - ord(): This function takes a single character (string of length 1) as an argument and returns an integer representing
      its Unicode code point.
    - When comparing strings, Python considers the Unicode values of the characters. If the first characters of two
      strings are the same, it moves to the next character and so on. A longer string is considered greater than a
      shorter string if all the characters up to the length of the shorter string are equal.
    'b' > 'a'    -> returns:  True
     ord('a')    -> returns 97
     ord('b')    -> returns 98
    'abc' > 'a'  -> returns:  True
    'abc' > 'b'  -> returns:  False

   Using 'in' check to see if something is inside a list
     2 in [1, 2, 3]  -> returns:  True
     4 in [1, 2, 3]  -> returns:  False

   Using 'not in' check to see if something is not inside a list
     2 not in [1, 2, 3]  -> returns:  False
     4 not in [1, 2, 3]  -> returns:  True

  Indentation:
    - python uses indentation to denote code block
    - should always use 4 spaces for indentation so your code will work other python code (psuedo standard)
    - make sure your text editor converts tabs to 4 spaces


  if/elif/else
    REPL example 1:
      >>> if False:
      ...     print ('was true')
      ... else:
      ...     print('was false')
      ...
      was false

    REPL example 2:
      >>> if len(name) >= 6:
      ...     print('name is long')
      ... elif len(name) == 5:
      ...     print('name is 5 char')
      ... elif len(name) >= 4:
      ...     print('name is 4 or more chars')
      ... else:
      ...     print('name is short')

6.4 Logic [Boolean] Operations

  Boolean Operators - and, or, not
    https://docs.python.org/3/library/stdtypes.html


  These are the Boolean operations, ordered by ascending priority:
     Operation     Result                                 Notes
     ---------     -----------------------------------    -----
     x or y        if x is true, then x, else y           (1)
     x and y       if x is false, then x, else y          (2)
     not x         if x is false, then True, else False   (3)

     Notes:
       1. This is a short-circuit operator, so it only evaluates the second argument if the first one is false.
       2. This is a short-circuit operator, so it only evaluates the second argument if the first one is true.
       3. not has a lower priority than non-Boolean operators, so not a == b is interpreted as not (a == b),
          and a == not b is a syntax error.


  Boolean operations
    not operations
      example 1
         >>> name = ""
         >>> not name   # name is empty, there it returns False, and not name returns True
         True
         >>> if not name:
         ...     print ("no name given")
         ...
         no name given

    or operations
      example 2
         >>> first = ""
         >>> last = "Thompson"
         >>> if first or last:
         ...     print ("The user has a first or last name")
         ...
         The user has a first or last name

         >>> last = ""
         >>> if first or last:
         ...     print ("The user has a first or last name")
         ...

         >>> last = ""
         >>> last_name = last or 'Doe'   # way to set default value using 'or'
         >>> last_name
         'Doe'

             Note: x or y        if x is true, then x, else y           (1)

         >>> 0 or 1 or 2    # 0 returns False, and 1 returns True
         1
         >>> 0 or 2 or 1    # 0 returns False, and 2 also returns True
         2

    and operations
      example 3
         >>> first = "Pat"
         >>> last = ""
         >>> if first and last:
         ...     print (f"Full name: {first} {last}")
         ... elif first:
         ...     print (f"First name: {first}")
         ... elif last:
         ...     print (f"Last name: {last}")
         ...
         First name: Pat

         >>> last = "Hall"
         >>> if first and last:
         ...     print (f"Full name: {first} {last}")
         ...
         Full name: Pat Hall

            Note: x and y       if x is false, then x, else y          (2)

         >>> 0 and 1
         0
         >>> 1 and 2
         2

#!/usr/bin/env python3

# BMI = (weight in kg / height in meters squared)
# BMI = (weight in lbs / height in inches squared) * 703


def gather_info():
    height = float(input("What is your height? (inches or meters) "))
    weight = float(input("What is your weight? (pounds or kilograms) "))
    # get system type plus lower case and strip whitespaces
    system = input("Are your measurements in metric or imperial units? ").lower().strip()
    # return multiple results as a tuple
    return (height,weight,system)

# define calculate_bmi with weight,height, & system inputs plus default value for system
def calculate_bmi(weight, height, system='metric'):
    """
    Note: This multi-line comment at beginning of a function is referred as a doc string
          and some tools convert doc strings to documentation
    Return the body mass index (BMI) for the given·
    weight, height, and measure systems.
    """
    if system == 'metric':
        bmi = (weight / (height ** 2))
    else:
        bmi = 703 * (weight / (height ** 2))
    return bmi


while True:
    height,weight,system = gather_info()
    if system.startswith("i"):
        bmi=calculate_bmi(weight,system='imperial', height=height)
        print(f"Your BMI is {bmi}")
        break
    elif system.startswith("m"):
        bmi=calculate_bmi(weight, height)
        print(f"Your BMI is {bmi}")
        break
    else:
        print("Error: Unknown measurement system. Please use imperial or metric")

   class argparse.ArgumentParser(prog=None, usage=None, description=None, epilog=None, parents=[],
      formatter_class=argparse.HelpFormatter, prefix_chars='-', fromfile_prefix_chars=None, argument_default=None,
         conflict_handler='error', add_help=True, allow_abbrev=True, exit_on_error=True)
    - Create a new ArgumentParser object. All parameters should be passed as keyword arguments


  Using argparse Steps:
    Creating a parser
     - The first step in using the argparse is creating an ArgumentParser object:
       >>> parser = argparse.ArgumentParser(description='Process some integers.')

    Adding arguments
     - Filling an ArgumentParser with information about program arguments is done by making calls to the add_argument()
       method. Generally, these calls tell the ArgumentParser how to take the strings on the command line and turn them
       into objects. This information is stored and used when parse_args() is called. For example:
       >>> parser.add_argument('integers', metavar='N', type=int, nargs='+',
                    help='an integer for the accumulator')

       >>> parser.add_argument('--sum', dest='accumulate', action='store_const',
                    const=sum, default=max,
                    help='sum the integers (default: find the max)')

    Parsing arguments
      - ArgumentParser parses arguments through the parse_args() method. This will inspect the command line, convert
        each argument to the appropriate type and then invoke the appropriate action. In most cases, this means a
        simple Namespace object will be built up from attributes parsed out of the command line:
        >>> parser.parse_args(['--sum', '7', '-1', '42'])
        Namespace(accumulate=<built-in function sum>, integers=[7, -1, 42])

   Namespaces in Python
    - A namespace is a collection of currently defined symbolic names along with information about the object that
      each name references.
    - You can think of a namespace as a dictionary in which the keys are the object names and the values are the
      objects themselves. Each key-value pair maps a name to its corresponding object.

import argparse

# parse the arguments
parser = argparse.ArgumentParser()
parser.add_argument('filename', help='the file to read')

else:
    with f:

        # reverse the order of the lines
        lines.reverse()

        # limit arg is specified, limit the number of lines in the lines list
        if limit:
            lines = lines[:limit]

        # use strip to remove newline char, and then reverse the contents of each line

8.7 Advanced iterations with List Comprehensions


  List Comprehensions
  https://docs.python.org/3/tutorial/datastructures.html#list-comprehensions

  List Comprehensions
   - List comprehensions provide a concise way to create lists.
   - Common applications are to make new lists where each element is the result of some operations applied to each member
     of another sequence or iterable, or to create a subsequence of those elements that satisfy a certain condition.

  - For example, assume we want to create a list of squares, like:
    >>> squares = []
    >>> for x in range(10):
            squares.append(x**2)
    >>> squares
    [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

    - Note that this creates (or overwrites) a variable named x that still exists after the loop completes.
    - We can calculate the list of squares without any side effects using:

       squares = list(map(lambda x: x**2, range(10)))

     or, equivalently:

       squares = [x**2 for x in range(10)]


  Python List Comprehension:
   https://www.geeksforgeeks.org/python-list-comprehension/
   - A Python list comprehension consists of brackets containing the expression, which is executed for each element along with
     the for loop to iterate over each element in the Python list.

   - Python List Comprehension Syntax
       Syntax: newList = [ expression(element) for element in oldList if condition ]

    Parameter:
        expression: Represents the operation you want to execute on every item within the iterable.
        element: The term "variable" refers to each value taken from the iterable.
        iterable: specify the sequence of elements you want to iterate through.(e.g., a list, tuple, or string).
        condition: (Optional) A filter helps decide whether or not an element should be added to the new list.

    Return:The return value of a list comprehension is a new list

  Note:
    map function
     - The map() function executes a specified function for each item in an iterable. The item is sent to the function as a parameter.
     Syntax
          map(function, iterables)
     Example:
       numbers = [1, 2, 3, 4]
       squared_numbers = list(map(lambda x: x**2, numbers))
       print(squared_numbers)
       # output
       [1, 4, 9, 16]

import os

import json
import shutil

try:

subtotal = 0.0

for path in receipts:
    with open(path) as f:

        content = json.load(f)
        subtotal += float(content['value'])

Note:
  glob vs iglob:
   - glob and iglob are both functions in the glob module that find files and directories whose names match a specified pattern.
    - The key difference lies in how they return the results.

      glob.glob():
        - This function returns a list of all paths that match the pattern.
        - It reads all the matching paths and stores them in memory before returning the list.

       glob.iglob():
        - This function returns an iterator that yields paths one at a time as they are found.
        - It doesn't store all the results in memory at once, making it more memory-efficient, especially when dealing with a large number of files.

import json
import shutil
import math

try:
    os.mkdir('./processed')

# use glob.iglob() to return list of receipt files since it returns an iterator sequence [reduces memory footprint]
for path in glob.iglob('./new/receipt-[0-9]*.json'):
    with open(path) as f:
        # load receipt JSON contents to 'content' dict
        content = json.load(f)
        subtotal += float(content['value'])
        # str.replace() to create destination file name (change dir path from ./new/' to './processed/')
        destination = path.replace('new','processed')
        # move processed receipt files from './new' directory to './processed' dir
        shutil.move(path,destination)
        print(f"moved '{path}' to '{destination}'")

# use old python print formatting to round off subtotal
#print("Receipt subtotal: $%.2f" % subtotal)
# use round() built in function to round subtotal result to 2 decimal digits
print(f"Receipt subtotal: ${round(subtotal, 2)}")

#!/usr/bin/env python3

import os
# requests provides HTTP API requests
import requests
import sys
from argparse import ArgumentParser

parser = ArgumentParser(description='Get the current weather information for your zipcode')
parser.add_argument('zip', help="zip/postal code to get weather for")
parser.add_argument('--country', default='us', help="zip/postal belongs to, default is 'us'")
args = parser.parse_args()

# expects Openweathermap API to be passed via OWM_API_KEY env variable
api_key = os.getenv("OWM_API_KEY")
if not api_key:
    print("Error: no 'OWN_API_KEY env variable provided")
    sys.exit(1)

# specify the Openweathermap URL for zip based weather
# https://api.openweathermap.org/data/2.5/weather?zip={zip code},{country code}&appid={API key}
url = f"http://api.openweathermap.org/data/2.5/weather?zip={args.zip},{args.country}&appid={api_key}"
# Use requests HTTP request to obtain the current weather
res = requests.get(url)

# verify successful URL request
if res.status_code != 200:
    print(f"Error talking to weather provider: {res.status_code}")
    sys.exit(2)

# print out the returned JSON weather data
print(res.json())

pgbackup
=========

CLI for backup remote PostgreSQL database either locally or to AWS S3.

Preparing the Development
-------------------------

1. Ensure ``pip`` and ``pipenv`` are installed.
2. Clone repository: ``git clone git@github:username/pgbackup``
3. ``cd`` into repository.
4. Fetch development dependencies ``make install``
5. Activate virtualenv: ``pipenv shell``


Usage
-----

Pass in a full database URL, the storage driver, and the destination.

S3 Example w/ bucket name:

::

    $ pgbackup postgres://bob@example.com:5432/db_one --driver s3 backupsBucket


Local Example w/ local path:

::

    $ pgbackup postgres://bob@example.com:5432/db_one --driver local /var/local/db_one/backups/dump.sql

Running Tests
-------------

Run tests locally using ``make`` if virtualenv is active:

::

If virtualenv is not active, then use:

::

    $ pipenv run make

from argparse import Action, ArgumentParser

known_drivers = ['local', 's3']

# create Action class - needed to handle 2 values for '--driver' argument
class DriverAction(Action):
    def __call__(self, parser, namespace, values, option_string=None):
        driver,destination = values
        if driver.lower() not in known_drivers:
            parser.error("Unknown driver. Available drivers are 'local' and 's3'")
        namespace.driver = driver.lower()
        namespace.destination = destination


def create_parser():
    parser = ArgumentParser()
    parser.add_argument('url', help="URL of the PostgreSQL database to backup")
    parser.add_argument('--driver', help="how & where to stora the back",
            nargs=2,
            action=DriverAction,
            required=True)
    return parser

  tempfile - Generate temporary files and directories
    Source code: Lib/tempfile.py
    - This module creates temporary files and directories.
    - It works on all supported platforms.
    - TemporaryFile, NamedTemporaryFile, TemporaryDirectory, and SpooledTemporaryFile are high-level interfaces
      which provide automatic cleanup and can be used as context managers. mkstemp() and mkdtemp() are lower-level
      functions which require manual cleanup.

    tempfile.TemporaryFile(mode='w+b', buffering=- 1, encoding=None, newline=None, suffix=None, prefix=None, dir=None, *, errors=None)
      - Return a file-like object that can be used as a temporary storage area.
      - The file is created securely, using the same rules as mkstemp().
      - It will be destroyed as soon as it is closed (including an implicit close when the object is garbage collected).

    tempfile.NamedTemporaryFile(mode='w+b', buffering=- 1, encoding=None, newline=None, suffix=None, prefix=None, dir=None, delete=True, *, errors=None)
      - This function operates exactly as TemporaryFile() does, except that the file is guaranteed to have a visible
        name in the file system (on Unix, the directory entry is not unlinked). That name can be retrieved from the name
        attribute of the returned file-like object.
      - Whether the name can be used to open the file a second time, while the named temporary file is still open,
        varies across platforms (it can be so used on Unix; it cannot on Windows).
      - If delete is true (the default), the file is deleted as soon as it is closed.
      - The returned object is always a file-like object whose file attribute is the underlying true file object.
      - This file-like object can be used in a with statement, just like a normal file.

import subprocess
import sys

def dump(url):
    try:
        return subprocess.Popen(['pg_dump', url], stdout=subprocess.PIPE)
    except OSError as err:
        print(f"Error: {err}")
        sys.exit(1)

def dump_file_name(url, timestamp=None):
    # get db name which is after last '/'
    db_name = url.split("/")[-1]
    # in url, query parameters start with '?' separater can be appeneded after db Name
    db_name = db_name.split("?")[0]
    if timestamp:
        return f"{db_name}-{timestamp}.sql"
    else:
        return f"{db_name}.sql"

Question 2
How do you create a package in a Python project?
Choices:
  - Put an __init__.py file in a directory with the desired name.     <------- correct answer
  - Name a Python file with the package name you want to create.
  - None of the answers listed are correct.
  - Prefix the file name with package_.

Correct Answer

  To create a package within your Python project, you will need to add an __init__.py file inside of a directory with the
  desired package name. All other Python files within that directory will be modules on the package.
