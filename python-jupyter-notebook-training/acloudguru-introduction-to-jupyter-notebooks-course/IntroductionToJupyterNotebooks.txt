2.2 Introduction to Data Structures and Pandas


  Pandas
    - open source library that provides high performance, easy to use data structures  
    - builds on Numpy
    - Package for data manipulation
    - Uses DataFrame objects from R
    - Well suited for many different kinds of data:
      - Tablar data
      - Ordered and unordered time series data
      - matrix data and row and column labels
      - any other form of statistical data sets

  Pandas Series:
   - a one-dimensional array-like object, similar to a column in a spreadsheet or SQL table. 
   - It consists of an ordered sequence of values of the same data type and an associated array of data labels, called its index.
  Pandas DataFrame:
   - a two-dimensional, tabular data structure with rows and columns. 
   - It can be thought of as a collection of Series objects that share the same index. 
   - Each column in a DataFrame is a Series, and the DataFrame itself can hold columns of different data types. 

   Notes:
     - panda series can have a label for each element (index=) 
     - panda series can use a key/value object, like a dictionary, when creating a Series where the key is the label and value is an element
       import pandas as pd
       calories = {"day1": 420, "day2": 380, "day3": 390}
       myvar = pd.Series(calories)
       print(myvar)
       # output
       day1    420
       day2    380
       day3    390
       dtype: int64
     - panda dataframes can have a column name (columns=) and row name (index=)
     - panda dataframes default column names are integers starting at 0 and incrementing by 1
     - panda dataframes default indexes are integers starting at 0 and incrementing by 1
     - Pandas DataFrames have two axis labels:
        axis 0: Identifies rows. Referred to as "index".
        axis 1: Identifies columns.

  numpy.arange
    numpy.arange([start=0, ]stop, [step=1, ]dtype=None, *, device=None, like=None)
      - Return evenly spaced values within a given interval.

  numpy.reshape
    numpy.reshape(a, /, shape=None, order='C', *, newshape=None, copy=None)
    - Gives a new shape to an array without changing its data.

  pandas dataframe attributes:
    columns
      - The column labels of the DataFrame.
    iloc
      - (DEPRECATED) Purely integer-location based indexing for selection by position.
    index
      - The index (row labels) of the DataFrame.
    loc
      - Access a group of rows and columns by label(s) or a boolean array.
    ndim
      - Return an int representing the number of axes / array dimensions.
    shape
      - Return a tuple representing the dimensionality of the DataFrame. (# of rows, # of columns)
    size
      - Return an int representing the number of elements in this object.

    import numpy as np
    import pandas as pd

    # find Jupyter current directory (place CSV file in this directory)
    !pwd

    # read in movie CSV data and set Title as index column
    df1 = pd.read_csv("IMDB-Movie_lesson_2_3.csv", index_col="Title")

    # verify data was read in - head by default reads 1st lines
    df1.head()

    # read last 2 lines
    df1.tail(2)

    # rename columns with lowercase and shorter names
    df1.columns = ['rank','genre','desc','dir','actor','year','length','rating','votes','rev','mscore']
    df1.head(2)

    # change 'index' name to 'title' (lowercase)
    df1.index.name = 'title'

    # use info() to report column related info (column name, non-null count, datatype)
    df1.info()

    # use describe() to report the count, mean, std deviation, min, max, etc
    df1.describe()

    # use 'share' report number of columns and rows in dataset
    df1.shape

    # report the number of non-null values
    df1.isnull().sum()

    # replace 'rev' column NaN (not a number) values with the 'rev' mean value
    df1['rev'].fillna(df1['rev'].mean(),inplace=True)
    # replace 'mscore' [metascore] column NaN (not a number) values with the 'mscore' mean value
    df1['mscore'].fillna(df1['mscore'].mean(),inplace=True)

    # after changs, report the number of non-null values
    df1.isnull().sum()

    # drop the rank column - Note: axis=0 impacts rows, and axis=1 impacts the columns
    df1.drop(['rank'],axis=1,inplace=True)

    # find mean of the movies grouped by year
    df1.groupby(['year'])[['length','rating','votes','rev','mscore']].mean()

    # find mean of the movies grouped by year sorted by revenue
    df1.groupby(['year'])[['length','rating','votes','rev','mscore']].mean().sort_values(by=['rev'], ascending=False)

    # sort 2012 movies by revenue
    df1[df1['year'] == 2012].sort_values(by=['rev'], ascending=False)

    # find highest rated movies in the Comedy and Action genres
    df1[df1['genre'].isin(['Comedy', 'Action'])].sort_values(by=['rating'], ascending=False)

    # find the best rated (in the top 99%) with the lowest revenue movies (in the bottom 25%)
    df1[(df1['rating'] > df1['rating'].quantile(0.99)) & (df1['rev'] < df1['rev'].quantile(0.25))]

    4.2 Visualizing Distributions and Relationships Using Graphs

      Visualizing relationships
        - Visualizing the relationship between various features in our dataset helps uncover patterns, 
          identify trends, and determine the dependencies between the features.
        - provides a correlation between the various features and help find outliers

        Scatter Plot
          - shows the relationship between two numerical features plotted on the x and y access
          - graphs plot points along the x and you axis for two values

        Scatter Plot - Benefits and Limitations
          Benefits
            - Can detect non-linear patterns
            - effectively spot outliers
          Limitations
            - showing more than two features may make the chart less readable

        Bubble Plot (bubble charts)
          - effective to present the relationship betwe three features
          - the x and y axes represents the first two numerical features, and the bubble size represents the 3rd.
          - graphs plot points along the x and y axis for 3 values where bubbles size is the 3rd value


        Bubble Plot (bubble Chart) - Benefits and Limitations
          Benefits
            - can compare 3 or more features
            - the bubble size can highlight the patterns and trends in the data
          Limitations
            - it is difficult to distinguish individual data points, especially when they overlap
            - lacks interactivity like zooming, filtering, or drill-down capabilities

      Data Distributions
        - Studying the data distribution provides insights like the skewness, mean and median of a specific 
          feature in the dataset. 
        - shows how our data is grouped or clustered over certain intervals

      Distribution graph Types

        Histogram
          - shows the magnitude of a value in the form of a line or bar format
          - they group the data into bins or buckets and perform counts on top of them
          - these graphs put values into buckets or bins and determine a measurement (amount, frequency,
            duration, density, etc)
             - example: quantity vs price with 50 bins

        Histogram - Benefits and Limitations
          Benefits
            - allows you to see the frequency distribution quickly
            - can present categorical data
          Limitations
            - the number of bins determines the granularity of the data
            - not well-suited for detecting outliers
               - outliers can completely distort the distribution and affect the interpretation of the data.

    4.3 Visualizing Comparisons and Compositions Using Graph

      Visualizing Comparisons
        - Visualizing comparisons in our data can provide a static snapshot of how different variables in our 
          dataset compare with one another and show how they change overtime.

      Comparison Charts

        Bar Chart
          - A graphical representation of data the uses bars to represent the frequency, count, or value of 
            different categories present in the feature
          - graphs that use lines (bars) to mark single variable values. 
          - provides a way to lookup and compare values

          Barchart vs Histogram:
            - histograms are used to represent the continuous data,
            - bar charts are used to represent the categorical data

          Bar Chart example1:
            US muscle cars (camaro, covette, mustang) vs price
            - take average price vs car name and show 1 bar for each car
             - bar charts can be vertical (car - x-axis; price y-axis) or horizontal (price - x-axis; car y-axis) 

          Bar Chart example2 :
            - comparing the number of star ratings for a mobile application in the app store
            - a bar for each star rating (1-star, 2-star, ..., 5-star)

          Bar Chart - Benefits and Limitations
            Benefits
              - easy to compare values of different categories visually
              - viewers don't need any prior knowledge about data to interpret the visualization
            Limitations
              - Cannot be used to represent continuous data
              - as the number of categories increase, the chart can quickly be cluttered

        Line Chart
          - graphs that use lines to show one or more variables changeing over time
          - that is, the x-axis shows when we measure the data, and the y-axis shows the actual value 
            during the measurement.

          Line Chart example1:
            US muscle cars (camaro, covette, mustang) vs price over time
            - price on Y-axix, date on x-axis, and 1 line per car for price over time created by
              plotting the car price points over time and connecting points with different color lines 
              for each car

          Line Chart example2 :
            - Ploting the price of Bitcoin over the past 3 years

          Line Chart vs Bar chart Summary 
            - can use bar charts to represent a single point in time, or a lookup value for our data,
            - can use line charts to show how our data changes over time.

          Line Chart - Benefits and Limitations
            Benefits
              - simple and easy to interpret
              - can be leveraged to compare trends in multiple categories at the same time
            Limitations
              - cannot be used to visualize categorical data

    Plotly
      - Plotly is a popular open-source Python library that is used for creating interactive data visualizations.
    
      - Plotly provides two main APIs for creating plots: the low-level Graph Objects API and the high-level Figure Factory API. 
      - The Graph Objects API is used for creating individual trace objects, which can be combined to create a plot. 
      - The Figure Factory API, on the other hand, provides pre-built functions for creating specific types of plots.
    
      1. Example of low level graph object using sine and cosine is given below:-
    
        import plotly.graph_objs as go
        import numpy as np
        
        # Generate some sample data
        x = np.linspace(0, 10, 100)
        y1 = np.sin(x)
        y2 = np.cos(x)
        
        # Create a plot
        fig = go.Figure()
        
        # Add a scatter plot for sin(x)
        fig.add_trace(
            go.Scatter(
                x=x,
                y=y1,
                mode='lines',
                name='Sin(x)',
                line=dict(color='red')
            )
        )
        
        # Add a scatter plot for cos(x)
        fig.add_trace(
            go.Scatter(
                x=x,
                y=y2,
                mode='lines',
                name='Cos(x)',
                line=dict(color='blue')
            )
        )
        
        # Update the plot layout
        fig.update_layout(
            title='Sine and Cosine Functions',
            xaxis_title='x',
            yaxis_title='y',
            font=dict(
                family='Arial',
                size=18,
                color='black'
            )
        )
        
        # Show the plot
        fig.show()
        
        figure8. Sine and Cosine function
        
      2. The below code illustrate how to use high level figure factory API to create a scatter float matrix.
        
        import pandas as pd
        import plotly.figure_factory as ff
        import numpy as np
        
        # Generate some sample data
        x = np.random.randn(100)
        y = np.random.randn(100)
        
        # Convert numpy arrays to pandas dataframe
        df = pd.DataFrame({'x': x, 'y': y})
        
        # Create a scatter plot matrix
        fig = ff.create_scatterplotmatrix(
            df,
            diag='histogram',
            index='y',
            height=800,
            width=800
        )
        
        # Update the plot layout
        fig.update_layout(
            title='Scatter Plot Matrix',
            font=dict(
                family='Arial',
                size=18,
                color='black'
            )
        )
        
        # Show the plot
        fig.show()
